# 👨‍👩‍👧‍👦 Family Support Management System

A modern full-stack platform designed to simplify family support, financial assistance, and household management. The system enables families, guardians, and administrators to manage support requests, track financial contributions, monitor expenses, and improve communication through a centralized digital platform.

# ⚙️ Installation

```bash

cd family-support-system
```

# 🎯 Project Goals

The Family Support Management System aims to strengthen family coordination by providing a secure and centralized platform for managing financial assistance, household expenses, support requests, family communication, and important events. The platform promotes transparency, accountability, and collaboration among family members while simplifying day-to-day management.
